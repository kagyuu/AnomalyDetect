# 実装構造修正(Executor完了時)

## 目的

* Executorによる実装(P102)・結合テスト実行(P103)が完了した時点で、`{ソースツリー}/INDEX.md` を実際のソースツリーと一致するように更新する。

## インプット文書

* 実装後のソースツリー
* 更新前の `{ソースツリー}/INDEX.md`

## アウトプット文書

* `{ソースツリー}/INDEX.md` (更新後)

### 動作内容

* `SKILL-P020-source-index.md` と同じ形式(INDEX形式)で、新規作成・編集されたファイル/ディレクトリを反映する。
* 削除されたファイル、役割が変わったファイルがあれば、記載を修正する。
* 空の目次のまま(P020時点で未実装だった)場合、またはP020が「初期化済みだが未実装」のハイブリッド形式で作成していた場合は、実装された内容で全面的に埋め、「(実装前)」の注記を除去する。
