# 影響分析(修正実施後)

## 目的

* P203で行った修正それぞれについて、他の機能・他のテストを壊していないかを確認する。
* 壊している疑いがある場合は、P202(修正計画)に差し戻して追加の修正タスクを作らせる。

## インプット文書

* `docs/P202-fix-plan/fixed/F000-{fix-name}.md` (今回修正した項目)
* `docs/P202-fix-plan.md` (残っている未解決項目)
* 変更されたソースコードの差分

## アウトプット文書

* `docs/P204-impact-analysis.md`

### アウトプットの記載内容

* 今回の修正ごとに、影響しうる他の画面・API・モジュール・既存のPASS済みテストを列挙する。
* 実際に既存テストを再実行して確認できる範囲は、この時点で軽く確認してよい(本格的な再実行はP205で行う)。
* 他機能を壊している疑いがある場合は、その内容を明記し、P202に差し戻して追加の修正タスクを起票する。
* 疑いがない場合は、その旨を明記してP205(結合テスト再実施)に進む。
* 本フェーズを複数回実行する場合(差し戻しループ)、過去の判定を上書き・削除せず、最新の判定を `docs/P204-impact-analysis.md` の冒頭に、過去の実行履歴を末尾の「実行履歴」章に保持する。

### アウトプットを参照する文書

* `docs/P202-fix-plan.md` (差し戻す場合、追加タスクの起票先)
* `docs/P205-*` (結合テスト再実施)

## 動作

* 共通指示以外は特になし
