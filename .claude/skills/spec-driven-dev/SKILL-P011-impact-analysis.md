# 影響分析(設計書横断レビュー起因)

## 目的

* `docs/P010-design-review.md` で列挙された矛盾点それぞれについて、修正が必要な箇所と影響範囲を分析する。
* このフェーズでは修正そのものは行わない。修正はP012で行う。

## インプット文書

* `docs/P010-design-review.md`
* `docs/P001-requirement.md` 〜 `docs/P009-acceptance-direction.md` (矛盾点に関連する箇所)

## アウトプット文書

* `docs/P011-impact-analysis.md`

### アウトプットの記載内容

* `docs/P010-design-review.md` の矛盾点ごとに、以下を整理する。

```markdown
## 矛盾点 #1

- 概要:
- 修正すべき文書と箇所:
- どちらの記述を正とすべきか(判断とその理由):
- 波及して確認・修正が必要になる他の文書・箇所:
- 修正の優先度: 高 / 中 / 低
```

* 「どちらの記述を正とすべきか」は、原則として上流工程の文書(P001に近いもの)を優先するが、機械的にではなく、要件を満たす上でどちらが妥当かを判断して明記する。判断がつかない場合は、判断がつかない旨と、判断に必要な情報を明記する(このフェーズで無理に決めない)。
* 波及確認が必要な文書は、直接の矛盾点だけでなく、P004(トレーサビリティマトリクス)・P007〜P009(目次・タスク一覧)への影響も含めて洗い出す。

### アウトプットを参照する文書

* `docs/P012-*` (設計書修正) が、本分析結果にもとづいて各設計書を修正する。

## 動作

* 共通指示以外は特になし
