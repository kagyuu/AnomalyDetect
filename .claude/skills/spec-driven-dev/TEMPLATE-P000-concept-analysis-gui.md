# P000 要求整理 (GUIアプリ用)

画面を持つアプリケーション向けのひな型。P000が本ファイルを複製して `docs/P000-concept-analysis.md` を作成し、**人間が記入する**。

* `<!-- 記入してください: … -->` が未記入箇所の目印。記入したらコメントごと消す。
* **必須**の章が1つでも未記入だと、P001へ進めない。**任意**の章は空欄のままでよい(P001がAgentの想定で補い、その箇所に★FIXME★を付ける。後から人間がまとめて確認できる)。
* 分からないことは「わからない」「おまかせ」と書いてよい。**空欄のままにするのと、「わからない」と書くのは違う**。前者は書き忘れかもしれないが、後者は判断をAIに委ねたという意思表示になる。
* **GUI・CLIのいずれにも当てはまらないアプリケーション**(APIサーバ、バッチ処理など)は、近い方のテンプレートをベースに章を読み替えて使う。★ACCEPTED★ 形態別のテンプレートを増やす案は採らなかった。アプリケーションの形態は際限がなく網羅できないうえ、章立ての大半(概要・技術・データ・非機能要件・対象外)はどの形態でも共通であり、差分は「画面と操作」か「コマンドと引数」かに集約されるため。残る制約として、APIサーバやバッチでは5章の見出し語(画面/操作)を読み替える手間が生じる。

以下がテンプレート本体。
