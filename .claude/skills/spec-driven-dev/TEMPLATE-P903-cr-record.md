# CR-NNN 対処記録

CR 1件の対処記録のテンプレート。**P903が作業開始時(実装に着手する前)に `docs/P903-cr-records/CR-NNN.md` として作成し**、以降 P903(完了時)・P904・P905 が自分の節を追記して完成させる。

* ファイル名の番号は、対応する変更要求 `docs/P901-cr-direction/CR-NNN.md` と**同じ番号**にする。要求と記録は番号だけで1対1に突き合わせられる。
* **どの節をどのフェーズが書くかは固定**である。他フェーズの節を勝手に書き換えない。
* 状態(`未対応`/`対応中`/`反映確認中`/`完了`/`却下`)はこのファイルには持たせない。状態の唯一の正は `docs/CR.md`(台帳)である。
* **却下する場合**: 却下を決めたフェーズがこのファイルを作成し、却下理由を書く(P901の時点で却下が決まる場合はP901が作成する)。その場合、以降の節は「却下のため該当なし」とする。
