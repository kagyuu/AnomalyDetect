## U008-T1: イベント本文の生成

### 【目的】

* `docs/P000-concept-analysis.md` が指定した 10 項目の書式で、1 イベントぶんの Markdown を生成する。

### 【作成・編集対象ファイル】

* `docs/P003-backend-spec.md` 11章 DS-12-01, DS-12-03

### 【実装内容】

1. **`render_event(event, metric_labels) -> str`** を作る。出力は次の形に**厳密に**従う(`docs/P001-requirement.md` 12章、人間に確認済みの確定仕様)。
   ```
   # イベントID( EVT-20260601-001 )

   * イベント種別 : ALG-B3 ローリング最小値の単調増加, ALG-B2 Mann-Kendall 傾向検定
   * 脅威度 : SEVERE
   * データ : jvm_gc / ou (Old 使用量) / container=app01, host=host01
   * 値     : 41.2→45.8→52.3→58.9→64.1→71.5→78.2→85→91.3
   * 開始   : 2026-06-01 03:00:00
   * 終了   : 2026-06-14 23:00:00
   * 現象   : {定型文}
   * 説明   : {判定根拠}
   * 原因候補 : {候補} (確度: 高) — {根拠}
   * 同時刻のその他のデータ :
     - {相関先}: 平常時 X → 期間中 Y (+Z%)
   ```
   * **先頭は `# イベントID( {ID} )`。** 丸括弧の前後に半角スペースがある点に注意。
   * **項目の行頭は `* `。** `docs/P000-concept-analysis.md` の `( イベント種別` は誤記であり、`* イベント種別` が正(`docs/P001-requirement.md` 20章 #5、人間に確認済み)。
   * 項目名の後のスペース数は上例に合わせる(`値`, `開始`, `終了` は全角 2 文字なので後ろに半角スペース 5 個で桁を揃える)。
2. **UI-04-02 を厳守する。すべての項目を必ず出力する。** 値が得られない場合も行を省略せず、定型文を書く。
   * `原因候補` が空 → `* 原因候補 : 該当する候補なし (確度: —)`
   * `同時刻のその他のデータ` が空 → `  - (同時刻に有意な変化を示す他のデータはありません)`
   * **省略すると、後段の LLM が「異常がない」と誤読する。**
3. **「値」欄の省略規則**(UI-04-01、DS-12-03)。
   * 値を `→` で連結する。
   * **9 点を超える場合は先頭 4 点 + `…` + 末尾 4 点**。
   * 数値は `f"{v:.4g}"`(有効数字 4 桁)。
4. **「現象」欄の定型文**(`docs/P002-frontend-spec.md` 4.3)。`shape` ごとに分岐する。

   | shape | 定型文 |
   | --- | --- |
   | `spike_up` | `平常時({平均値})に対し {倍率}倍({値})に跳ね上がった。前後の点は平常範囲` |
   | `spike_down` | `平常時({平均値})に対し {比率}({値})に落ち込んだ` |
   | `sustained` | `{継続時間}にわたり平常範囲を上回った状態が継続した` |
   | `floor_rise` | `最低値が{期間}上昇し、回復しない、{負荷指標の状況}` |
   | `trend_up` | `{期間}で {開始値}から{終了値}へ増加した(平均 {勾配}/日)` |
   | `level_shift` | `{時刻}を境に水準が {前水準}から{後水準}へ移行し、元に戻らない` |
   | `seasonal_dev` | `{曜日}{時刻帯}の平常値({平常値})に対し {値}であった` |

   * 埋め込む値は `event.detail` の各アルゴリズムの統計量から取る。値が無い場合は「不明」と書き、行自体は省略しない。
   * `floor_rise` の `{負荷指標の状況}` は、相関先に `active_connections` または `run` の有意な増加があれば「負荷増を伴う」、なければ「負荷増はない」とする。
5. **「説明」欄**は、`event.algorithms` の各アルゴリズムについて、`detail` の統計量と閾値を 1 行ずつ並べる。例:
   ```
   * 説明   : 6時間窓のローリング最小値が連続34窓にわたり単調増加した(ALG-B3, 総増加 51.1)。
              Mann-Kendall検定でも有意な増加傾向を検出した(ALG-B2: S=+1842, p<0.001, Sen勾配=+3.6/日)。
   ```
   * 継続行はインデントして読みやすくする。
6. **「データ」欄**は `{source} / {metric} ({和名}) / {系列キーの各要素}`。`metric_labels: Dict[str, str]` で和名を引く(例: `ou` → `Old 使用量`, `pend` → `待機ジョブ数`)。**11 メトリクスすべての和名を定義する。**
7. 時刻の書式は `YYYY-MM-DD HH:MM:SS`。
