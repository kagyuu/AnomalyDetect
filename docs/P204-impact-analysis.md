### 8.1 テストが検出していない要件未達 — NFR-009(再現性)

* **同一入力・同一設定で 2 回実行しても `report.md` が一致しない。** 実測(30 日分): F003 前は 308 行差(バイト数も 14,393,736 / 14,393,778 と不一致)、F003 後は 34 行差(バイト数は一致)。
* 原因は `correlate.py` の `_build` にある `rank()` である。`mu` と `mu_pct`、`ou` と `ou_pct`、`eu` と `eu_pct` は**互いに比例するメトリクスで変化率が数学的に同値**になり、ソートキーの `-magnitude` が DuckDB の並列集計に由来する浮動小数点の下位ビットで揺れて順序が入れ替わる。`[:MAX_CORRELATIONS]`(上位 10 件)の境界にかかると、どちらが残るかも変わる。
* **F001 / F003 が持ち込んだものではない。** F003 前のコード単独で再現する。**F003 のバッチ分割は揺れを 308 行から 34 行へ減らしたが、解消はしていない。**
* **A003(再現性)は PASS している。** 14 日分のベースラインで 3 回実行して一致を確認しているが、その規模ではイベント数が `correlate.EVENT_BATCH`(500)を下回り、集計も単一パーティションに収まるため現象が現れない。**テストの網羅性の欠落である。**
