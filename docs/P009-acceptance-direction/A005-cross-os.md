# 【テストID】A005 — 両 OS での一致

## 【目的】

## 【対象モジュール】

## 【前提条件】

* `docs/P009-acceptance-direction.md` 4.1 のビルド確認が、**Windows 側と Linux 側の両方で**成功していること。**片方でも失敗した場合は `BLOCKED`。**
* WSL2 の Ubuntu が利用可能であること。`wsl -d Ubuntu -- python3 -c "import duckdb"` が成功すること。**利用できない場合は `NOT RUN` として記録し、P302 の「未整備事項・人間による確認事項」へ引き継ぐ。**

## 【事前準備】

1. スイート初期化がこのスイートの実行で 1 回だけ済んでいること(Windows 側)。
2. Windows 側と Linux 側に、それぞれ独立した一時作業ディレクトリを作る。

## 【実行手順】

1. **Windows 側**でアプリを起動し、`report.md` を取得する。
2. **Linux 側**で `python3 app/tools/gen_testdata.py <linux-tmp>/normal` を実行し、生成データを作る。
3. **Windows 側の生成データと Linux 側の生成データを、バイト単位で比較**する(生成の決定性)。
4. **Linux 側**でアプリを起動し(入力は Windows 側で生成したデータ = `app/tests/_work/normal/logs`)、`report.md` を取得する。
5. 両方の `report.md` を、実行日時の行を除いて比較する。
