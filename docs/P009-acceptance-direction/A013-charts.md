# A013 — チャート出力の確認(※CR-009)

* 対象CR: [CR-009](../P901-cr-direction/CR-009.md)
* 実装: `app/tests/acceptance/test_a013_charts.py`
* 対応する要件: **FR-130〜FR-136**(`docs/P001-requirement.md` 13.2)

---

## 1. 試験の目的

**アプリを外側から起動し、生成物として確かめる。**

チャートは補助的な機能だが、**壊れても実行が止まらないため、
壊れていることに気づきにくい**。とくに次の 2 つは、エラーを出さずに
機能が消える形で起きうる。

| 危険 | 起きること |
| --- | --- |
| **重ね合わせが 1 枚も出ない** | 依頼者の要求の半分が、エラーなしに消える。**実際に一度起きた** |
| リンク切れ・孤児ファイル | レポートの画像が表示されないか、無駄なファイルが残る |

---

## 2. 事前準備

ベースラインのテストデータ(14 日分)を用いる。
設定は `H.make_dist()` で複製した配布物の `settings.properties` を差し替えて与える。

**3 通り実行する。**

| ラベル | 設定 | 目的 |
| --- | --- | --- |
| `on` | `enabled = true`, `min_severity = FATAL` | 本体 |
| `on2` | 同上 | **再現性の比較用** |
| `off` | `enabled = false` | 無効化の確認・サマリ比較の基準 |

---

## 3. 試験項目

| # | 確かめること | 期待 |
| --- | --- | --- |
| 1 | SVG が出力される | `charts/` に 1 つ以上。進捗に「チャートを」が出る |
| 2 | **リンクとファイルが 1 対 1** | 集合として完全一致(片方にしか無いものが 0 件) |
| 3 | **リンクが相対パス** | `charts/` で始まり、`/` `\` `:` を含まない |
| 4 | リンク先が実在する | 全リンクについてファイルがある |
| 5 | **重ね合わせが実際に出る** | 「同時に発生したアノマリー」を含む SVG が 1 枚以上 |
| 6 | SVG の形が正しい | `<svg ` で始まり `</svg>` で終わり、`<polyline` を含む |
| 7 | **再現性** | 2 回実行して**全 SVG がバイト単位で一致**(NFR-009) |
| 8 | 無効化 | `enabled = false` で SVG 0 件・リンク 0 件、進捗に「無効です」 |
| 9 | **サマリが変わらない** | `on` と `off` のサマリが一致し、`![` を含まない |
| 10 | サマリが 4K に収まる | 各サマリファイルが 4,000 バイト以下 |
| 11 | 本文が肥大しない | 増加が 1 リンクあたり 200 バイト未満 |

### #5 が最も重要である

**`SEVERE` は定義上「観点2 の検知」であり、観点2 のイベントには
同時アノマリーが付かない**(CR-002)。脅威度順だけで対象を選ぶと、
**重ね合わせが構造的に一度も描かれない。**

**実装中に実際にこの状態になった。** 15 枚のチャートが出力され、
エラーも警告も出ないまま、**全ての図で折れ線が 1 本しか無かった。**
是正として選別の枠を 2 つに分けた(DS-15-03)。**本項目はその回帰試験である。**

### #9・#10・#11 の狙い

**CR-004 で「4K トークンのローカル LLM が集計できる」ようにした設計を壊さないこと。**
チャートは人間向けであり、**サマリに入れてはならない。**
本文に入るのも 1 行のリンクだけで、図そのものは別ファイルに置く。

通常のスイートに含めてよい範囲である。
